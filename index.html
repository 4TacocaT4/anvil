Anvil needs JavaScript to run

This page builds your training plan in the browser, so nothing renders until the script runs. If you are seeing this message:

  • Open index.html directly in Chrome, Edge or Firefox — right-click the file and choose Open with. A document preview pane or file viewer will not run it.
  • If it is already open in a browser, check that JavaScript is not blocked for local files by an extension or policy.
